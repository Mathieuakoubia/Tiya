  ÉTAPE 7 — CRÉER LES SESSIONS TWIN/SQUAD (Custom Actions)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Avant de naviguer vers une page Twin/Squad, il faut créer une
  session dans Firestore et récupérer son ID.

  Créer une Custom Action FF : createTwinSession(routineName)

  import 'package:cloud_firestore/cloud_firestore.dart';
  import 'package:firebase_auth/firebase_auth.dart';

  Future<String> createTwinSession(String routineName, String partnerUid) async {
    final uid = FirebaseAuth.instance.currentUser?.uid;
    if (uid == null) throw Exception('Non authentifié');
    final ref = await FirebaseFirestore.instance.collection('twin_sessions').add({
      'launchedBy'  : uid,
      'partnerUid'  : partnerUid,
      'routineName' : routineName,
      'status'      : 'waiting',
      'createdAt'   : FieldValue.serverTimestamp(),
    });
    return ref.id;
  }

  Appeler cette action AVANT de naviguer vers la page Twin.
  Le sessionId retourné est passé en Page Parameter.

  Même logique pour Squad : createSquadSession(routineName, squadId)
  Code dans squad_service.dart (déjà existant).

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Ces 3 fonctions DOIVENT être déployées avant le launch.
  Elles ne peuvent pas être faites dans FlutterFlow.

  1. onRoutineCompleted
     Déclencheur : onDocumentCreated squad_sessions/{id}
     Action : FieldValue.increment(1) sur squads/{squadId}.niveauBouclier
     Sécurité : vérifier que status == 'completed' et que l'auteur est membre

  2. onAudioCapsuleCreated
     Déclencheur : onDocumentCreated audio_capsules/{id}
     Action : valider durée (Storage metadata < 2MB) → mettre status='delivered'
     Sécurité : vérifier que senderUid est membre du squadId

  3. deleteAccount
     Déclencheur : HTTP callable (appelée depuis l'app)
     Action : supprimer users/{uid}, anonymiser les messages, retirer des squads
     Requis RGPD : droit à l'effacement

  Commande de déploiement :
    firebase deploy --only functions
