  1. CE QUI A ÉTÉ IMPLÉMENTÉ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ✅ face_emotion_analyzer.dart
     Modèle Savchenko EfficientNet-B2 (enet_b2_8.tflite) via tflite_flutter.
     Entrée : image 260×260px normalisée [0.0, 1.0].
     Sortie : 8 émotions → Valence/Arousal (modèle circumplex Russell).
     Mapping des 8 émotions :
       anger (-0.70, +0.80) | contempt (-0.40, +0.20)
       disgust (-0.60, +0.40) | fear (-0.65, +0.80)
       happiness (+0.80, +0.50) | neutral (0.0, 0.0)
       sadness (-0.50, -0.20) | surprise (+0.20, +0.70)
     Fallback : FaceEmotionResult.noFace si visage non détecté.

  ✅ voice_stress_analyzer.dart
     Analyse acoustique locale : RMS Energy + Zero-Crossing Rate + Pitch
     (autocorrélation simplifiée — Yin algorithm).
     Capture 3s PCM 16kHz mono → fichier WAV temporaire → analyse → suppression.
     Aucun fichier audio persistant. Aucune donnée ne quitte l'appareil.
     isStressed = arousal > 0.55 ET valence < -0.15.
     Remplace Hume AI pour la validation des capsules audio.

  ✅ biometric_service.dart
     Orchestrateur du pipeline complet (9 secondes) :
       Phase 1 (6s) : Caméra → MLKit face detection → TFLite → V/A facial
       Phase 2 (3s) : Microphone → PCM → features acoustiques → V/A vocal
       Fusion : 60% visage + 40% voix (ou 100% voix si visage non détecté)
     Fermeture caméra IMMÉDIATEMENT après la capture (économie batterie).
     Sauvegarde Firestore : UNIQUEMENT auraState (hex), auraScore, lastAuraAt.
     Instance singleton : biometricService (partagée dans toute l'app).

  ✅ selfie_flash.dart
     Widget Flutter UI pour la capture biométrique Selfie Flash.
     Affiche les 4 étapes visuelles : caméra → voix → calcul → résultat.
     Paramètres : moment ('before'/'after'), onAuraReady(AuraResult).
     Fallback UI si erreur → "Analyse indisponible, routine continue".

  ✅ audio_capsule_send.dart — Hume AI supprimé
     L'analyse d'amplitude (NoiseMeter + seuil 62dB) est remplacée par
     VoiceStressAnalyzer.isStressed (analyse acoustique locale complète).
     Plus aucune dépendance à noise_meter pour cette routine.

  ✅ pubspec.yaml
     Ajout : tflite_flutter: ^0.10.4
     Ajout : image: ^4.2.0 (traitement d'image — crop, resize)
     Ajout : assets/models/ (dossier pour enet_b2_8.tflite)

  ✅ Règles de sécurité RGPD respectées
     - Flux vidéo traité en mémoire, non sauvegardé
     - Fichier audio PCM supprimé immédiatement après analyse
     - Aucun embedding, vecteur ou image n'est transmis à Firestore
     - Seul le résultat final (hex couleur Aura + score 0-1) est persisté

  3. CE QUI MANQUE / LIMITATIONS ACTUELLES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ⚠ Analyse vocale — Précision limitée (Phase 1)
    L'implémentation actuelle (RMS + ZCR + Pitch) est une approximation
    heuristique. Elle fonctionne pour bloquer les capsules clairement stressées
    mais ne reconnaît pas les nuances émotionnelles fines.
    → Pour la Phase 2 : remplacer par Wav2Vec2 TFLite (à calibrer avec Yannick
      Benezeth). Prévoir un modèle Wav2Vec2 préentraîné en français.

  ⚠ Seuils Valence/Arousal — À calibrer
    Les seuils de l'Aura (V ≥ 0.2, A ≤ 0.3 pour Sereine, etc.) sont des
    estimations initiales. Calibrer avec les données de la bêta (500 premières
    utilisatrices, point avec Yannick Benezeth).

  ⚠ Preprocessing image — Vérifier l'orientation
    Sur certains Android, l'image caméra peut être tournée de 90°/270°.
    Ajouter une correction d'orientation via ExifInterface si les résultats
    TFLite semblent aberrants sur Android.
    → Voir InputImageMetadata.rotation dans google_mlkit_face_detection.

  ⚠ SelfieFlash pas encore intégré dans Reset Flash
    reset_flash.dart ne déclenche pas encore SelfieFlash.
    Pour intégrer :
      1. Ajouter SelfieFlash en paramètre optionnel de ResetFlash
      2. Lancer _push(context, SelfieFlash(moment: 'before', ...))
         AVANT de lancer ResetFlash
      3. Relancer SelfieFlash(moment: 'after', ...) à la fin
    → Cette étape sera faite lors de l'intégration UI finale.

  ⚠ Transition caméra → micro sur iOS
    Sur iOS, AVCaptureSession doit être explicitement fermée avant
    d'ouvrir le microphone. La caméra est déjà fermée dans
    biometric_service.dart (cam.dispose() avant la Phase 2).
    → Tester sur iPhone physique et vérifier qu'il n'y a pas de conflit.

  4. ARCHITECTURE FINALE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Flux de données (tout on-device) :

  Caméra frontale
    ↓ Flux vidéo (6s, RAM uniquement)
  MLKit Face Detection
    ↓ Bounding box visage
  Crop + Resize → 260×260px
    ↓ Tenseur normalisé [0,1]
  TFLite enet_b2_8.tflite
    ↓ [anger, contempt, disgust, fear, happiness, neutral, sadness, surprise]
  Mapping Russell Circumplex
    ↓ Valence_face, Arousal_face  ← RIEN n'est sauvegardé ici

  Microphone
    ↓ PCM 16kHz mono (3s, fichier WAV temporaire)
  RMS + ZCR + Pitch (Yin)
    ↓ Valence_voice, Arousal_voice  ← fichier WAV supprimé ici

  Fusion (60% visage + 40% voix)
    ↓ Valence_final, Arousal_final
  Mapping Aura
    ↓ Couleur hexadécimale (#9DD9D2 / #C4F9FF / #E89B7A / #D97A7A)

  Firestore users/{uid}
    auraState: "#9DD9D2"   ← SEUL CE CHAMP est sauvegardé
    auraScore: 0.78        ← score 0-1 pour l'App State
    lastAuraAt: Timestamp
